# Plugin contract

The reader resolves the Vault through `TRADINGBOT_KNOWLEDGE_VAULT`, a per-user path saved by `scripts/configure_vault.py`, or a sibling `TradingBot-Knowledge` directory. All knowledge, captured source evidence, and RAW paths are resolved within that Vault. Ordinary retrieval does not require the original TradingBot checkout. Optional HPZR6 reference excerpts require `TRADINGBOT_ENGINE_ROOT` and exact registry hash verification. Default search and relation traversal exclude known-invalid Order_B/C; explicit retrieval warns. Rule answers must respect Vault authority, retrieval policy, and sync review state; unresolved rules and unapproved computed output are not promoted to canonical truth.
