# Plugin contract

The plugin reads a configurable standalone Vault. The Vault index and notes determine entity membership, status, authority, validity, and relations. Plugin code contains no named trading-rule statuses. Ordinary retrieval never writes to the Vault and never runs the trading engine. Production checkout access is limited to optional registry-pinned reference excerpts; maintainer synchronization is a separate explicit command.

An answer should identify the retrieved note and source path, distinguish normative content from executable or external evidence, and preserve warnings and sync review state. Missing or stale evidence is an error or an explicit availability result; it is never silently replaced with remembered content.
