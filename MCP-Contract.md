# MCP contract

`mcp.json` starts `scripts/launch_mcp.py`, which selects a Python interpreter with the SDK and runs `mcp_server.py` over stdio. Configure the cloned Vault with `scripts/configure_vault.py`, `TRADINGBOT_KNOWLEDGE_VAULT`, or a sibling `TradingBot-Knowledge` directory. The server writes no trading output. Captured source excerpts are hash checked against the Vault manifest. Optional external HPZR6 excerpts require `TRADINGBOT_ENGINE_ROOT` and an exact hash match with `06_SOURCE/References/registry.json`. Default search and relation traversal hide known-invalid Order_B/C; pass `include_quarantined=true` for diagnostic access. Hosts without MCP can use `vault_cli.py` or read the Vault directly.
