# Version pinning

`vault_cli.py verify` checks the Vault-local source manifest, indexed note metadata and relations, retained physical RAWs, exact windows, and unregistered physical RAW inventory. A malformed retained RAW window is reported as a verification failure. `verified_pins_ok` covers registered evidence; `inventory_complete` also requires no unregistered RAW files or sidecars. Overall `ok` and the CLI exit code require both. The Vault's `_SCHEMA/build_indexes.py --check` additionally validates schemas, relations, and derived indexes. A maintainer post-commit synchronization captures exact working-tree bytes only for clean, tracked project paths listed in the manifest. Dirty paths remain untouched and are reported for review; source changes update hashes and mark dependent claims for review. An index-build failure rolls back source and index writes; a write exception also triggers restoration of files changed during that synchronization. Excluded modules and references are not automatically restored. GitHub publication is a separate action.
