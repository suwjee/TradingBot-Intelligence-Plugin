# Version and integrity

The package version is declared in plugin.json. Compatible integrity/compatibility repairs increment the existing patch revision; a breaking public contract requires an explicitly reviewed version decision. This release moves 0.3.7 to 0.3.8, preserving the eight public tools and stable IDs while adding canonical-name/alias resolution, complete-note byte identity, retrieval-time Source currentness and disclosed Reference-scope warnings.

Current Source and local References are pinned by _INDEX/source-hashes.json and the pinned 06_SOURCE/References/registry.json. Runtime never bakes their versions, hashes, counts or filenames into code. Registry, local Manifest pin, bytes and declared document version/direction must agree. External Engine verification is optional and must agree when configured.

All trusted JSON rejects duplicate keys at every nesting level and NaN/Infinity. Indexed canonical frontmatter is compared in full with its index row, with exact JSON types, and validated by the current Draft 2020-12 schemas. Only derived file/content_sha256/content_bytes fields are excluded from authored metadata equality; the complete-note hash/size is checked separately. A declared require_note_identity contract rejects removed pins. Relation edges are checked against canonical typed arrays before traversal, and returned neighbors' declared evidence is verified.

The Vault builder validates canonical metadata, exact captured inventory, embedded Source and links; two independent builds must be byte-identical. Plugin knowledge verification checks non-RAW pins; full-data additionally verifies registered input inventory. Zero datasets/windows/fixtures are valid EMPTY_BY_DESIGN. Doctor requires verified local references and a completed actual MCP initialize/list/call round trip for every discovered tool. No integrity gate establishes market trading correctness.

The official package builder uses its explicit allowlist. Every included runtime/document file must match editable root bytes. Build before installation and verify the built copy; no user installed cache is updated automatically by this release.

Runtime retrieval and verification enforce the optional declared current_contract, including closed inventory and per-entity status/authority/version/owner constraints. Captured Engine pins cannot redirect or suppress external verification by changing their repository-relative mapping. Bootstrap containment is checked before required index/schema/registry reads. Both Source excerpt routes and Reference-through-Source excerpts retain the same currentness and documented-scope protections as their canonical retrieval routes.
